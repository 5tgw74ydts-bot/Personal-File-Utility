# Privacy Policy

Personal File Utility is a private application used to transfer, back up, and verify files in a Google Drive account with the account owner's authorization.

**Data access and use**

The application accesses Google Drive data only with the account owner's permission and uses that access solely for file transfers, backups, and verification.

**Data sharing**

The application does not sell user data, use it for advertising, or share it with other users or third parties. It is not available as a public service.

**Authorization**

The account owner can revoke access at any time through their Google Account settings.
